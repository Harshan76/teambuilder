Evaluator Defense: What Did the AI Component Actually Contribute?

This evaluation module directly demonstrates what machine learning contributes relative to a conventional rule-based heuristic:

Baseline Mechanics (Linear Weights)

The baseline computes deterministic weighted scores across criteria. It excels at greedy matching for specific required skills, but can suffer from archetype redundancy when high-scoring students possess overlapping strengths.

AI/ML Mechanics (Clustering + Orthogonal Fill)

The Scikit-learn K-Means model uncovers latent student archetypes across 20+ continuous feature dimensions without manual rule tuning. The assignment engine then enforces cross-cluster diversity, fostering complementary team breadth.

Evaluator Integrity Guarantee: K-Means is an unsupervised discovery algorithm. Cluster separation does not prove real-world group project success. If a labeled dataset of historical student outcomes becomes available, supervised classifiers (e.g. Random Forest, Gradient Boosting) can be integrated seamlessly into the evaluation pipeline.
